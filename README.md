# Supermart Sales EDA

Exploratory Data Analysis on supermarket sales data using Python.

## Highlights
- Univariate, bivariate and multivariate analysis
- Sales trends by branch, product line and customer type
- Correlation and distribution analysis

## Tech
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter

## Run
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook EDA_Supermart_Sales.ipynb
